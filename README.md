# Python Polygon Art

## Description
This project uses Python Turtle Graphics and Object-Oriented
Programming (OOP) to create colorful polygon artwork.

## Features
- A reusable Polygon class
- Regular polygons with different numbers of sides
- Independent colors and pen sizes
- Static polygon artwork with 20 objects
- Animated polygon artwork with 8 objects
- Object movement using sine and cosine functions

## Files
- polygon_shape.py
- 05_polygon_art_starter.py
- 06_animated_polygon_art_starter.py

## Requirements
- Python 3
- Turtle module
- Tkinter

## How to Run

Run static artwork:

python 05_polygon_art_starter.py

Run animated artwork:

python 06_animated_polygon_art_starter.py
